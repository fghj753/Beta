# Сайт автосервиса — деревня Тетерино

Адрес: Московская область, Можайский район, деревня Тетерино, 70Г. Телефон: +7 (926) 656-57-43. Ежедневно 08:30–17:30.

## Запуск (нужен Node.js 22.5+)

```sh
ADMIN_PASSWORD=ваш_пароль node server.js
```

- Сайт: `http://localhost:3000` (порт: `PORT=8080`).
- Чаты сотрудников: `http://localhost:3000/admin` (логин `admin`, пароль из `ADMIN_PASSWORD`; если не задан, временный пароль печатается при запуске).
- За прокси (nginx) добавьте `TRUST_PROXY=1`, чтобы лимиты считались по IP клиента.

## Чат

Кнопка в правом нижнем углу. Клиент пишет, сотрудник отвечает на `/admin`. Всё сохраняется в SQLite: `data/chat.db` (таблицы `chats`, `messages`). Копируйте эту папку для бэкапа. Кнопка «Заказать эвакуатор» открывает чат с готовым текстом.

## Структура

- `server.js` — статика, API чата, база SQLite, пароль для `/admin`.
- `public/index.html`, `css/styles.css`, `js/app.js` — сайт.
- `public/js/chat.js` — виджет чата клиента.
- `public/admin.html`, `js/admin.js`, `css/admin.css` — панель сотрудников.

Карта: кнопки ведут в Яндекс Карты (поиск по адресу и построение маршрута).
